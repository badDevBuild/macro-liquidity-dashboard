# 看板运行与生产部署边界

## 运行模型

数据抓取和页面服务是两条分开的路径：

1. 北京时间每天 07:30，数据任务从 14 条官方或可信转发路径抓取、解析并做质量门禁；
2. 只有通过门禁的运行才会原子替换 `data/snapshots/latest.json`；
3. 看板服务只读正式快照和 `data/channel.sqlite3`，不在用户打开页面时临时抓取外部网站；
4. 浏览器加载最新正式快照；网络暂时不可用时，可以显示设备上最后一次成功加载的快照，并明确标记为离线缓存。

这样，某个来源临时失败或用户在手机上刷新页面，都不会把半份数据写进正式看板。

## 本地启动

```bash
python3 scripts/serve_dashboard.py --host 127.0.0.1 --port 8876
```

健康检查：

```bash
curl http://127.0.0.1:8876/healthz
```

主要只读接口：

- `GET /api/dashboard`：总览、传导、账本和来源健康所需的完整模型；
- `GET /api/status`：最近正式快照、数据影子运行，以及数据与 Agent 各自的 14 天门禁进度；
- `GET /api/series?metric_id=<id>&range=1m|3m|1y|5y|all`：单项历史序列；`metric_id=net_liquidity_proxy` 返回按周对齐的流动性参考值历史；
- `GET /healthz`：服务进程健康检查。

## 缺失与降级

- 12 项中至少 10 项可分析，且每个关键分组满足最低数量时，允许以降级状态发布；
- 缺失值保持为 `null`，不会被显示成 `0`，也不会由 Agent 猜测或插值；
- 看板会显示缺失项、缓存项、过期项、观测日期不一致和来源链接；
- 门禁失败时，页面保留上一份通过门禁的正式快照，同时披露最近一次尝试失败；
- 因此偶尔缺 1–2 项不会让晨间看板整体停摆，但也不会隐藏证据缺口。

## PWA 与手机访问

页面采用移动端优先布局，并提供 Web App Manifest。生产环境在 HTTPS 下部署后，可用 Safari 或 Chrome 的“添加到主屏幕”安装。离线能力只保留最后一次成功加载的正式快照，不会把过期缓存伪装成实时数据。

开发环境的 `localhost` 可以使用 PWA 能力。页面 HTML 使用网络优先、离线回退，带版本号的静态资源使用缓存优先，避免新版本长期卡在旧首页；局域网裸 HTTP 地址不满足正式 Service Worker 安全条件，所以手机生产访问必须使用 HTTPS。

### Tailscale 私有验收入口

在 Tailscale Serve 尚未启用时，可以让第二个只读看板进程仅监听采集主机的 Tailscale 地址：

```bash
python3 scripts/serve_dashboard.py --host <TAILSCALE_IP> --port 8876
```

同一 Tailnet 的另一台设备可通过 `http://<TAILSCALE_IP>:8876/` 访问。该地址受 Tailscale 网络隔离和传输加密保护，但浏览器层仍是 HTTP，因此适合私有验收，不作为最终 PWA 生产入口，也不会取代 HTTPS 与访问控制门禁。

### 可选进程托管

可以用两个用户级 LaunchAgent 分别托管只读页面服务：

- 本机实例监听 `127.0.0.1:8876`；
- 私有验收实例监听 `<TAILSCALE_IP>:8876`。

两个作业都可以设置 `RunAtLoad` 和 `KeepAlive`。LaunchAgent 文件包含绝对路径和主机地址，属于部署者本机配置，不应直接提交。它们只负责页面和只读 API，不负责抓取数据；每天 07:30 的数据更新由独立调度任务运行。

## Agent 已进入每日网页流程

当前数据抓取、解析、单位换算、质量判断、代理值和分项贡献全部由可复算脚本完成。大模型不参与数据通道，也不填补缺失数据。

数据任务成功后，现在会自动触发一条独立的 Codex Agent 影子任务。它使用当前 ChatGPT 订阅登录，以 `gpt-5.6-sol` 和中等推理强度读取已经发布的正式快照，输出带证据边界的晨间解读，例如“今天变化由谁驱动”“哪些观察日期不一致”“哪些信号互相矛盾”。不需要额外 API Key。

影子分析写入 `data/analysis/shadow/`。网页会显示通过证据校验、且与当前快照一致的分析。连续 14 个有效观察日和人工语义复核用于记录长期稳定性，不阻止个人查看。Agent 失败、超时或登录失效只会留下状态与通知，完全不影响数据和图表更新。

当前已加入过去 24 小时新闻和未来 90 天事件。程序先保存原文、来源 URL、时间和内容哈希，再把结构化条目交给 Agent 筛选。新闻只是来源主张，不会被当成可复算指标；新闻发布时间晚于数据观察日时，Agent 不得声称它造成了该数据变化。

## 生产部署前门禁

当前不要直接把 Python 开发服务暴露到公网。正式发布至少需要：

1. 14 个来源完成 14 个不同自然日的影子运行，发布率和来源成功率通过硬门禁；
2. Agent 完成 14 个有效观察日，并通过证据门禁与人工语义批准；
3. 以 `127.0.0.1` 绑定应用服务，由反向代理提供 HTTPS；
4. 为私人投资看板配置访问控制，不使用公开匿名链接；
5. 使用受控进程托管，配置启动恢复、健康检查和异常告警；
6. 备份 SQLite、正式快照和必要原始证据，并先确认保留期再实施清理；
7. 验证手机 PWA 安装、缓存更新、降级显示和跨时区日期；
8. 对外发布前再做一次安全审计和真实设备验收。

## 投资决策边界

流动性参考值采用 `联储总资产 - TGA - RRP`，准确术语是“净流动性代理值”。它用于解释联储与财政账本变化，不等于可以直接买入股票或加密资产的现金。长期趋势按美联储周度日期对齐周度 TGA 和最近 RRP；市场方向还需结合增长、通胀、实际利率、美元、信用条件和加密内部资金管道判断。
