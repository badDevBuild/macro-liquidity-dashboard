# GPT Pro 仓库评审整改记录（2026-09）

本记录对应公开仓库初始提交 `46ce1586` 的评审。原则是：先复现，再修复；没有证据的建议不按“已完成”处理。

## 数据正确性

- **Bybit 未平仓量双边口径：已修复。** 当前值改用 `singleOpenInterestValue`，历史值改用 `singleOpenInterest`。三家交易所统一标记为 `single_sided_v2`；旧双边快照在刷新前不可进入 Agent 分析；方法版本不同不计算涨跌。2026-09-20 的真实接口抽样中，50 个未平仓量时间戳与 50 个标记价格 K 线时间戳全部对齐。
- **派生指标继承错误质量：已修复。** 利差只有在两个基础指标都明确 `available_for_analysis=true` 时才可分析，并保留两端来源、质量、正式快照日期和公式版本。
- **发布时新鲜、阅读时已过期：已修复。** 页面读取时按频率重新计算新鲜度，同时保留发布时的质量事实。服务、更新任务、数据新鲜度分开报告；运行时过期会阻止 Agent 继续使用旧证据。
- **正式快照与历史查询串版：已修复并开始迁移。** 历史接口锁定正式快照选中的来源、观察日期和发布时间。数据库新增 append-only `observation_versions`，同一天后续修订不会改写旧发布视图。迁移前已经存在的旧行无法凭空恢复过去版本，后续每次运行都会积累可重放版本。
- **跨次比较口径不一致：已修复。** 比较前检查单位、来源、频率、覆盖范围、方法版本、窗口、作用域和观察方法。不一致时 `change=null` 并给出原因。Polymarket 同一事件的最高概率选项发生切换时，不再把两个不同选项的概率相减。
- **稳定币缺失值与 ETF 不完整窗口：已修复。** 稳定币历史分项缺失时整段比较为未知，不把缺失当零；ETF 5/20 日必须分别有 5/20 个已结算交易日，否则数值为 `null`，并公开实际/预期覆盖数。连续流入/流出遇到不合理日期缺口时停止。

## 运行与公开边界

- **Service Worker 越权清缓存：已修复。** 只删除 `macro-liquidity-` 前缀且不再使用的缓存。真实 Chromium 已验证同域 `another-app-cache` 保留。
- **内部状态公开：已修复。** 公开状态改为严格 DTO，只包含周期 ID、状态、开始/结束、成功与否、短错误码、公开版本和模块状态。发布包只复制两个健康摘要和一个裁剪后的周期状态；构建时扫描本机路径、堆栈和常见凭证片段。
- **整周期并发和超时：已修复。** 整个周期增加非阻塞文件锁、统一阶段超时、唯一 `cycle_id`、每周期状态文件，并把周期 ID 传给所有子进程。单模块超时返回明确的 124，而不是无限挂住。
- **公开路径错误返回首页：已修复。** 不存在的静态路径返回 404；API 错误仍返回不含本机路径的 JSON。

## 前端一致性

- **范围请求竞态：已修复。** 每个图表容器只保留最后一次选择，旧请求会被 `AbortController` 取消；响应版本与当前首页版本不一致时拒绝绘图。真实 Chromium 已验证“慢的 1 年请求”不能覆盖后发的“快的 1 月请求”。
- **抽样漏掉尖峰、缺口被连线：已修复。** 抽样改为每桶保留极小值和极大值，并保留首尾；异常日期缺口会断线。普通图表可展开查看最近 30 条数据，接口保留所选范围全部数据。
- **离线混用不同发布版本：已修复。** 首页和历史接口都返回 `release_id`；前端缓存键包含发布版本；离线时只会请求该页面版本对应的历史缓存，并明确显示离线状态。
- **移动端：已验证。** 390×844 的真实 Chromium 页面宽度等于视口宽度，没有横向溢出。
