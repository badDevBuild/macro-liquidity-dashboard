# 流动性参考值：每日余额与最新变化合计

2026-09-09，版本 `daily-tga-v1`。

## 两个数字回答不同问题

- **最新变化合计**：保留用户指定的混合周期口径，Δ最近联储周值 − Δ最近每日 TGA − Δ最近每日 RRP。每项注明自己的起止日期和周期；不是单日净流入，不能把这个数累加成历史余额。
- **参考余额与历史走势**：每日 TGA 与 RRP 必须同一个观察日；联储使用该观察日或之前最近一条周值，最多沿用 10 天。余额、图表终点、周/月/季/年变化共用这一条日序列。

如果 RRP 更新得比 TGA 快，首屏分项仍展示 RRP 最新变化；余额和趋势停留在两者最新共同数据日，并展示该日期。

财政部 `WTREGEN` 是周平均，仅保留独立指标，不再参与参考值计算。它不是周三当天余额。

## 时间和缺失

- 历史按观察日重建，可能含官方后续修订，不是当时实时可得数据的回测。联储的周三余额一般之后才公布，不声称周三当时已经知道。
- `observed_at` 是余额所属日期；`fetched_at` 是本系统抓取时间，**不是**官方发布时间。没有官方精确发布时间就不编造。
- 每日 TGA/RRP 缺少同日记录时不计算该日，不补零、不延用日值、不拿周平均填缺口；联储超过 10 天也不计算。
- 周/月变化从统一日序列选取目标日期或之前最近的有效点，保留真实起点日期。首屏最新变化合计不受此规则替代。
- 历史读取不越过正式快照各指标的观察日期，补历史不能偷偷引入比正式快照更晚的记录。

## 采集与恢复

每日采集继续使用 `config/sources.json` 中 Treasury Fiscal Data 的每日收盘余额 API，最近 30 条每日记录滚动入库并记录修订，无需改变每天 07:30 更新计划。

完整补取命令：`python3 scripts/backfill_tga_daily.py --direct`。分页上限20页，每页1000条；校验总数、日期唯一、单位、数值范围、未来日期后才入库。原始响应和来源 URL 持久保存；失败可重试，不修改正式快照，也不自动发布。

本次官方现行账户标签覆盖 2022-04-18 至 2026-09-04，1100 条每日余额，配对 RRP 后1095个日期。更早记录未接入，选5年/全部历史时明确显示覆盖不足。数据差异是历史方法修正，不能当作今天的资金变化。

## Agent 与回归

Agent 提示词升级为 v9。`net_liquidity_proxy_weekly` 暂作兼容编号，但内容和名称均为日序列趋势；新增 `methodology_version`，跨版本不计算“较上一轮变化”。旧提示词结果不作为新口径的当前分析，需重新生成并校验。

回归检查：每日而非周平均、同日配对、联储只更新一次、缺失不补齐、快照边界、历史与余额一致、分项符号/单位合计、跨版本不误报市场变化。
