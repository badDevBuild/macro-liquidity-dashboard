# Mobile directions v1 prompt

Mode: built-in `image_gen`

Use case: `ui-mockup`

Create one high-fidelity landscape comparison board containing three clearly different portrait mobile dashboard concepts side by side. Each phone screen is approximately a 390×844 viewport. This is a direction probe, not a final implementation.

- Direction A, exact header: `方向 A  晨间观测台`. Editorial morning rhythm, one concise status sentence first, then three ranked drivers, then a compact contribution or waterfall chart.
- Direction B, exact header: `方向 B  结构账本`. Dense but calm ledger, aligned tabular numbers, source freshness and observation dates highly visible, expandable metric rows.
- Direction C, exact header: `方向 C  流动地图`. A vertical causal map connecting 联储, 财政, 货币市场, 市场传导, with compact sparklines and directional connectors.

Use a restrained warm off-white shell, system sans typography with tabular numerals, and four low-chroma data roles: brick red, moss green, ink blue, and ochre. Make the interface calm, trustworthy, accessible, and suitable for early-morning mobile reading.

Avoid crypto neon black, navy-and-gold wealth templates, purple gradients, gradient text, glassmorphism, glowing borders, generic identical card grids, giant hero-number SaaS cards, investment recommendation language, logos, trademarks, and watermarks. All data values are illustrative.
